# Calculator App

A simple Python calculator application with REPL, history, and configuration support.

## Features
- Basic arithmetic operations
- REPL interface
- Calculation history
- Configurable settings
- Input validation
- Memento pattern for undo/redo

## Getting Started
1. Clone the repository
2. Install dependencies: `pip install -r requirements.txt`
3. Run the calculator: `python app/calculator_repl.py`

## Testing
Run tests with:
```
pytest
```
